# 윤사무실 설치 안내

**컴퓨터를 잘 몰라도 따라 할 수 있게** 적었습니다. 설치 파일을 받는 것부터, 앱을 처음 켰을 때
나오는 준비 화면을 끝내는 것까지 순서대로 나옵니다. 전체 10~15분쯤 걸립니다(설치 중 기다리는
시간이 대부분입니다).

**중간에 파란 경고 화면이 한 번, 검은 창이 한두 번 나옵니다.** 둘 다 정상이고, 어떻게 넘어가는지
아래에 그대로 적어 두었습니다. 놀라서 [실행 안 함]을 누르지만 않으면 됩니다.

| 필요한 것 | |
|-----------|--|
| 윈도우 | Windows 10 또는 11 (64비트) |
| 인터넷 | 설치 중에 프로그램을 내려받습니다 |
| 계정 | Claude 계정 — 아직 없으면 설치 도중 만들 수 있습니다 |

---

## 1. 설치 파일 받기

받을 파일은 이름이 이렇게 생겼습니다.

```
YunOffice-Setup-0.20.0-x64.exe
```

가운데 숫자(`0.20.0`)는 버전이라 받는 시점에 따라 다릅니다. **`YunOffice-Setup-`으로 시작하고
`-x64.exe`로 끝나면** 맞는 파일입니다.

> 📷 여기에 스크린샷: 파일을 받는 화면(메일 첨부·메신저·공유 폴더 등 실제로 전달하는 방법) —
> 어떤 파일을 눌러야 하는지 그 파일 이름이 보이게

받은 파일은 **다운로드 폴더**에 저장됩니다. 브라우저 창 오른쪽 위 화살표(↓)를 누르면 방금 받은
파일이 보입니다.

> **브라우저가 다운로드를 막을 수도 있습니다.** Chrome이나 Edge는 널리 쓰이지 않는 프로그램
> 파일을 받을 때 "일반적으로 다운로드되지 않는 파일"이라며 멈춰 세우기도 합니다. 그럴 때는
> 그 줄의 `⋯`(점 세 개)를 눌러 **[유지]** 를 고르면 내려받아집니다. 문구는 브라우저와 버전에
> 따라 조금씩 다릅니다.
>
> 📷 여기에 스크린샷: 브라우저 다운로드 목록에서 파일이 차단된 모습과 `⋯` → [유지] 메뉴

## 2. "Windows의 PC 보호" 경고 넘기기 — 여기가 가장 중요합니다

받은 파일을 **더블클릭**하면, 설치가 시작되기 전에 **파란색 큰 창**이 하나 뜹니다.

```
Windows의 PC 보호

Microsoft Defender SmartScreen에서 인식할 수 없는 앱의 시작을 차단했습니다.
이 앱을 실행하면 PC에 문제가 발생할 수 있습니다.

              [ 추가 정보 ]        ← 글씨 링크

                                    [ 실행 안 함 ]
```

**이 화면에는 [실행] 버튼이 아예 없습니다.** 여기서 대부분 포기합니다. 다음 두 단계를 그대로
하세요.

1. 왼쪽 아래의 **[추가 정보]** 를 누릅니다. (버튼이 아니라 작은 글씨 링크처럼 보입니다)
2. 그러면 아래에 **앱 이름**과 `게시자: 알 수 없는 게시자`가 나타나고, **[실행 안 함] 왼쪽에
   [실행] 버튼이 새로 생깁니다.** 그 **[실행]** 을 누릅니다.

> 📷 여기에 스크린샷 ①: [추가 정보]를 누르기 **전** 화면 — [실행 안 함]만 있고 [실행]이 없는 상태.
> [추가 정보] 위치에 빨간 동그라미
>
> 📷 여기에 스크린샷 ②: [추가 정보]를 누른 **뒤** 화면 — 앱 이름·"알 수 없는 게시자"와 함께
> [실행] 버튼이 생긴 상태. [실행] 위치에 빨간 동그라미

### 왜 이런 경고가 뜨나요

윈도우는 **돈을 내고 산 인증서로 서명된 프로그램**과, 이미 아주 많은 사람이 내려받아 문제가
없었던 프로그램을 알아봅니다. 윤사무실은 개인이 만들어 소수에게 나눠 주는 앱이고, **인증서
서명을 하지 않았습니다.** 그래서 윈도우 입장에서는 "처음 보는 프로그램"이고, 처음 보는
프로그램에는 일단 이 경고를 띄웁니다.

즉 **"나쁜 것을 발견했다"가 아니라 "아는 것이 없다"** 는 뜻입니다. 이 경고는 앞으로도 계속
뜹니다(새 버전을 받을 때마다 다시 뜹니다).

> **다만 "그러니 무조건 안전하다"고 말할 수는 없습니다.** 이 경고를 지나가는 판단의 근거는
> 프로그램 자체가 아니라 **이 파일을 누구에게 받았는가**입니다. 아는 사람에게 직접 받은
> 파일일 때만 [실행]을 누르세요. 인터넷에서 주워 온 같은 이름의 파일이라면 누르지 마세요.

### 백신이 막을 수도 있습니다

서명이 없는 데다 이 앱은 설치 과정에서 **PowerShell과 winget 같은 윈도우 기본 도구를 대신
실행**합니다. 백신 프로그램(알약·V3·Windows 보안 등)이 이 조합을 의심스럽게 보고 파일을
지우거나 실행을 막는 경우가 있습니다.

- 파일이 **저절로 사라졌다면** 백신이 격리한 것입니다. 백신의 격리 목록(보호 기록)에서 복원하거나,
  예외로 등록한 뒤 다시 받으세요.
- 백신 설정을 바꾸는 것이 부담스러우면, **파일을 준 사람에게 알려 주세요.** 혼자 판단해서 백신을
  통째로 끄지는 마세요.

> 📷 여기에 스크린샷: 백신이 차단·격리 알림을 띄운 모습(재현되는 PC에서 찍히면)

## 3. 설치하기

[실행]을 누르면 평범한 설치 창이 뜹니다. **설치 위치를 고를 수 있고**, 특별히 바꿀 이유가
없으면 나오는 대로 [다음] → [설치]를 누르면 됩니다.

- 설치가 끝나면 **바탕화면에 `윤사무실` 아이콘**이 생깁니다.
- 설치 자체는 보통 1분 안에 끝납니다.

> 📷 여기에 스크린샷: 설치 창(설치 위치 선택 화면)과, 설치 완료 후 바탕화면에 생긴 `윤사무실` 아이콘

바탕화면의 **윤사무실**을 더블클릭해 앱을 켭니다.

> 설치 없이 바로 쓰는 `YunOffice-Portable-...-x64.exe`(포터블) 파일도 있습니다. 더블클릭하면
> 그 자리에서 바로 실행됩니다. **2단계의 파란 경고는 이 파일에도 똑같이 뜹니다.**

## 4. 첫 실행 — 준비 마법사

앱을 처음 켜면 창 가운데에 **`윤사무실을 쓸 준비를 합니다`** 라는 화면이 뜹니다. 오른쪽 위에
`3~5분이면 끝납니다`라고 적혀 있습니다.

왼쪽에 여섯 단계가 늘어서 있고, 지금 어디까지 왔는지 표시(`✔` 끝 / `●` 진행 중 / `○` 대기)가
계속 바뀝니다.

| | 단계 | |
|--|------|--|
| 1 | 준비물 확인 | 이 컴퓨터에 뭐가 있는지 봅니다 |
| 2 | 프로그램 설치 | 없는 것을 앱이 대신 깝니다 |
| 3 | Claude 로그인 | **직접 하셔야 합니다** |
| 4 | Figma 연결 | 건너뛸 수 있어요 |
| 5 | 첫 회사 만들기 | 이름만 적으면 됩니다 |
| 6 | 완료 | |

첫 화면의 **[시작하기]** 를 누릅니다. (지금 하기 싫으면 [나중에 하기]를 눌러도 되고, 나중에
오른쪽 위 **☰** 안의 **[설치 마법사 다시 열기]** 로 언제든 다시 들어올 수 있습니다.)

> 📷 여기에 스크린샷: 마법사 첫 화면 — 왼쪽 단계 목록과 [시작하기]·[나중에 하기] 버튼이 함께 보이게

### 1단계 · 준비물 확인

`이 컴퓨터에 무엇이 있는지 확인합니다`라는 화면에서 앱이 몇 초 동안 조사합니다. 세 가지가
목록으로 나옵니다.

| 목록에 나오는 이름 | 없으면 |
|---------------------|--------|
| **팀 활동을 화면에 그리는 기록기 (Python)** | 사무실 화면이 조용합니다(아무도 안 움직입니다) |
| **팀원을 실행하는 프로그램 (Claude Code)** | 팀원이 일을 못 합니다 |
| **실수를 되돌리는 장치 (Git)** — 없어도 됨 | 되돌리기를 쓸 수 없습니다 (`없음 (권장)`으로 표시) |

이미 있는 것은 `있음 · 3.13.14`처럼 **실제로 확인한 버전**이 옆에 적힙니다. 없는 것이 있으면
`○가지가 이 컴퓨터에 없습니다. 다음 화면에서 무엇을 깔지 보여 드립니다.`라고 알려 줍니다.

**[다음 — 무엇을 깔지 보기]** 를 누릅니다.

> 📷 여기에 스크린샷: 준비물 확인 화면 — 있는 항목(✔)과 없는 항목(·)이 섞여 있는 목록

### 2단계 · 프로그램 설치 — 관리자 창이 뜰 수 있습니다

`이 프로그램들을 설치합니다` 화면에는 **무엇을, 누가 만든 것을 까는지** 그대로 적혀 있습니다.
예를 들어 Python 줄에는 `Python.Python.3.13`, `만든 곳: Python Software Foundation`이 보입니다.

그 아래에 이 안내가 있습니다.

> 설치 중 Windows가 "이 앱이 변경하도록 허용하시겠습니까?"를 물을 수 있습니다. [예]를 눌러 주세요.

**Python을 설치할 때 실제로 이 창이 뜰 수 있습니다.** 화면이 어두워지면서 파란 방패가 있는
작은 창이 올라옵니다. 놀라지 말고 **[예]** 를 누르세요. [아니요]를 누르면 그 설치만 취소되고,
화면에 무엇이 빠지는지 설명이 나옵니다(다시 시도할 수 있습니다).

> 📷 여기에 스크린샷 ①: 설치 동의 화면 — 패키지 이름·만든 곳과 "이 앱이 변경하도록 허용…" 안내 문구가 함께 보이게
>
> 📷 여기에 스크린샷 ②: 실제로 뜬 윈도우 관리자 확인(UAC) 창 — [예] 위치에 빨간 동그라미

**[설치 시작]** 을 누르면 진행 화면으로 바뀝니다.

```
설치하는 중입니다
시간이 걸립니다(보통 2~5분). 조용해 보여도 진행 중이니 앱을 끄지 마세요.
```

항목마다 `내려받는 중` → `설치 중` → `확인 중` → `완료`로 바뀌고, 옆에 `1분 20초 경과`처럼
시간이 계속 올라갑니다. **숫자가 올라가고 있으면 멈춘 게 아닙니다.** 몇 분 동안 아무 변화가
없어 보여도 그렇습니다.

> **앱이 대신 깔아 주는 것은 여기까지입니다.** 프로그램을 내려받아 설치하는 일만 대신합니다.
> 다음 단계의 **로그인은 반드시 사람이 직접** 해야 합니다.

> 📷 여기에 스크린샷: 설치 진행 화면 — 한 항목은 `설치 중`, 다른 항목은 `완료`, 경과 시간이 보이는 상태

전부 끝나면 **[다음]** 이 나타납니다.

### 3단계 · Claude 로그인 — 직접 하셔야 하는 부분

`Claude에 로그인합니다` 화면입니다. 누르기 전에 이렇게 예고해 줍니다.

> **곧 검은 창이 하나 열립니다. 그 창은 신경 쓰지 않으셔도 됩니다.**
> 1. 잠시 뒤 브라우저가 열립니다 → 거기서 로그인하세요.
> 2. 로그인이 끝나면 이 화면이 저절로 다음으로 넘어갑니다.
>
> **검은 창에 무언가 입력할 필요는 없습니다.** "Or paste the redirect URL here:" 같은 글이
> 보여도 그대로 두세요.

**[로그인 창 열기]** 를 누르면,

1. `윤사무실 - Claude 로그인`이라는 **검은 창**이 뜹니다. 여기에는 아무것도 입력하지 않습니다.
2. 잠시 뒤 **브라우저**가 저절로 열립니다. 거기서 Claude 계정으로 로그인하세요(계정이 없으면
   그 화면에서 만들 수 있습니다).
3. 로그인이 끝나면 **앱이 알아서 알아채고** 다음 단계로 넘어갑니다. 앱 화면에는 그동안
   `브라우저에서 로그인을 마치기를 기다리는 중…`이 떠 있습니다.

> 📷 여기에 스크린샷 ①: [로그인 창 열기]를 누르기 전 화면(검은 창 예고 문구가 보이게)
>
> 📷 여기에 스크린샷 ②: 열린 검은 창 + 브라우저 로그인 화면

**브라우저 창이 안 뜨거나 놓쳤다면** [로그인 창이 안 보여요 — 다시 열기]를 누르고, 이미 다른
곳에서 로그인을 마쳤다면 [이미 로그인했어요 — 지금 확인]을 누르세요. 3분이 지나도 안 끝나면
`3분 안에 끝나지 않았습니다 — 창에서 마친 뒤 "다시 확인"을 눌러 주세요`라고 나옵니다. **이때도
검은 창은 닫히지 않습니다** — 거기서 마저 끝내면 됩니다.

### 4단계 · Figma 연결 — 건너뛰어도 됩니다

`기획안과 화면설계서는 Figma에 그립니다. 지금 연결하지 않아도 나머지는 전부 쓸 수 있습니다.`

방식은 3단계와 똑같습니다 — **[Figma 연결하기]** 를 누르면 검은 창(`윤사무실 - Figma 연결`)이
뜨고 브라우저에서 인증하면 됩니다. 지금 필요 없으면 **[건너뛰기 — 나중에 할게요]** 를 누르세요.
나중에 ☰에서 연결할 수 있습니다.

### 5단계 · 첫 회사 만들기

`어떤 일을 시키실 건가요? 이름만 적어 주세요.`

**회사 이름** 칸에 이름을 적습니다(처음에는 `첫 프로젝트`가 들어 있습니다). 적는 동안 아래에
`만들어질 위치: 내 문서 › 윤사무실 › <이름>`이 표시됩니다.

**[만들기]** 를 누르면 폴더를 만들고, 팀원과 설정까지 한 번에 갖춰 줍니다. 무엇이 만들어졌는지
목록으로 보여 줍니다(`폴더 생성`, `훅 설치…`, `팀원 ○명 추가`, `CLAUDE.md 생성…` 등).

- 이름에 `\ / : * ? " < > |` 같은 글자는 쓸 수 없습니다.
- 이미 쓰던 폴더가 있으면 [이미 있는 폴더를 쓸게요]로 그 폴더를 고르면 됩니다.

> 📷 여기에 스크린샷: 회사 이름을 적고 만들어질 위치가 표시된 화면 + [만들기] 후 결과 목록

### 6단계 · 완료

`준비가 끝났습니다 / 오른쪽 입력창에 시키실 일을 적어 보세요.`


## 6. 잘 안 될 때

### "설치는 됐는데 앱이 아직 못 찾고 있습니다"

윈도우는 **이미 켜져 있는 프로그램에게는** 새로 깔린 프로그램의 위치를 알려 주지 않습니다.
그래서 방금 설치한 것이 앱 눈에만 안 보이는 일이 생깁니다. 화면에 나오는 **[앱 다시 시작]**
버튼을 누르면 앱이 스스로 껐다 켜지면서 잡힙니다. (그 버튼이 없으면 앱을 닫았다가 바탕화면
아이콘으로 다시 켜세요.)

### "이 컴퓨터에서는 자동 설치를 쓸 수 없습니다"

자동 설치는 윈도우의 `winget`이라는 기능을 씁니다. **회사 PC는 이 기능을 정책으로 막아 두는
일이 흔하고**, 윈도우가 오래됐으면 아예 없습니다. **고장이 아닙니다.**

이때는 [설치 시작] 버튼 대신 각 줄에 **[다운로드 페이지 열기]** 가 나옵니다. 눌러서 공식
페이지에서 직접 받아 설치한 뒤, **[설치했어요 — 다시 확인]** 을 누르세요.

### 설치가 실패했다고 나올 때

화면에 **실패한 이유가 그대로 적힙니다.** 그 문구에 따라 할 수 있는 버튼이 함께 나옵니다.

| 화면에 나오는 말 | 하실 일 |
|------------------|---------|
| `설치가 취소됐습니다…` | 관리자 확인 창에서 [아니요]를 누른 경우입니다. [다시 시도] |
| `인터넷에 연결되어 있지 않아 내려받을 수 없습니다.` | 인터넷을 확인하고 [다시 시도] |
| 그 밖의 오류 | [다운로드 페이지 열기]로 직접 설치 후 [설치했어요 — 다시 확인] |

**한 항목이 실패하면 거기서 멈춥니다.** 실패한 채로 다음 것을 깔지 않기 때문입니다 — 무엇이
됐고 무엇이 안 됐는지가 화면과 어긋나지 않게 하려는 것입니다.

### 설치가 5분 넘게 안 끝날 때

무인 설치는 **5분까지만 기다립니다.** 넘으면 `5분 안에 끝나지 않았습니다`로 끝나고 다시 시도할
수 있습니다. 인터넷이 느린 곳에서 나기 쉽습니다.

### 앱을 지우려면

윈도우 **설정 › 앱 › 설치된 앱**에서 `윤사무실`을 찾아 제거하면 됩니다. 만들어 둔 작업 폴더
(`내 문서 › 윤사무실 › …`)는 그대로 남습니다.
